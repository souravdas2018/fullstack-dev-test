# fullstack-dev-test

Imagine a dashboard built for social-media marketers to instantly understand how organic videos are performing. At the top, big-number cards show our most important KPIs. Below, three distinct charts give depth at a glance:

### Metrics to track

* 3-Second Views
* Total Plays
* Share Rate
* Average Watch Time

### How to show them
1. **Bar Chart** of the **Top 5 Videos by 3-Second Views**
2. **Line Chart** of **Daily 3-Second Views** over the **past week**.
3. **Bubble Chart** plotting **Average Watch Time** (x-axis) vs. **Share Rate** (y-axis), with **bubble size** proportional to **Total Plays**


## Technical Requirements
* A Node.js/Express backend
* An endpoint for each chart
* Data should a self-contained dummy data generator. No need for a database
* Vue 3 (Composition API), Vue Router, Axios for the frontend
* At least one automated test for frontend(e.g. Jest and Vue testing library) and backend(e.g. Jest/Supertest) each


## How to submit
Open a pull request against this repository containing:
* Your complete implementation under backend/ and frontend/
* At least one automated test on each side
* The INSTALL.md file that describes how to setup and run the project
* Clean, readable code and sensible folder layout


## Evaluation Criteria

Please submit your pull request with your complete implementation within 4 days of receiving this brief to be considered.
